Version 3 closes a design system that had drifted into twenty surface fills, seven corner radii and three separate page headers, and fixes a long list of things that were quietly not working underneath it.

## What changed

- A closed token set: four surfaces, two hairlines, three radii, one focus ring, replacing roughly twenty ad-hoc alpha variants
- A brand derived from the logo artwork rather than a saturated default, on a warm near-black page instead of pure #000
- Macros read green, blue and yellow, so no macronutrient shares a colour with the primary action or the error state
- One header, one panel, one tab bar, one disclosure and one empty state across the app and the public site
- A mobile tab bar with the log action in the thumb zone, and a log sheet that opens wherever you are
- Corrected activity multipliers: sedentary was 1.0, which made TDEE identical to BMR
- Select chevrons, icon button shapes, toast stacking and the FAQ animation all fixed for browsers other than Chrome
- Offline navigation, a real install prompt, safe-area handling and one chrome colour for the installed app
- The landing page now shows the product working, using the same charts the app renders
- A typecheck that actually runs: the script compiled nothing, hiding 38 real errors including four defects in Google sign-in

As always, everything here is in the open-source repository, and your data stays exportable.
