Version 3.8 cuts backend latency and network chatter across the app, redesigns the blog with a tighter reading layout and rewritten guides, and fixes a batch of modal, mobile, and chart rough edges.

## What changed

- Backend speed: authenticated requests resolve linked users directly from SQLite instead of calling Clerk on every request, SQLite runs with WAL performance tuning and a sort-covering history index, and session updates throttle to once per 15 minutes
- Lower bandwidth and memory: nginx serves gzip-compressed static assets, TanStack Query stops redundant 15 to 60 second background polling now that live SSE sync handles updates, and backend metrics and caches use bounded memory
- Editorial blog redesign: articles drop stock hero photos in favor of a 65ch reading column, sticky table of contents, tabular data tables, and takeaway callouts, with all core nutrition guides rewritten in one plainspoken voice
- Cleaner app states: Home hides confusing zero targets with an inline link to Goals, Goals explains missing expenditure data directly instead of leaving an empty box, Analytics plots unlogged days as gaps rather than fake zero-calorie cliffs, and Profile leaves unset height and weight empty with placeholders
- Interaction and mobile fixes: modals use a topmost Escape stack and ref-counted scroll lock, Pro upgrade modals close cleanly on backdrop click, Habit card hover actions work again on desktop, signed-in users no longer see double headers on public pages, and the mobile Settings save bar sits above the tab bar
- Self-hosting: one new database migration (0027_optimize_indexes) runs automatically on startup

As always, everything here is in the open-source repository, and your data stays exportable.
